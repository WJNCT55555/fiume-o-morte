# Fiume o morte! · 意大利卡尔纳罗摄政 1919

一个关于 1919–1924 年**阜姆**（Fiume / Rijeka）的历史政治模拟游戏。

你是**加布里埃莱·邓南遮**——「指挥官」（Il Comandante）。1919 年 9 月 12 日，你带着两千五百名军团兵从 Ronchi
走进这座城市。1920 年 9 月 8 日，你在省督府的阳台上颁布《卡尔纳罗宪章》，宣布成立**意大利卡尔纳罗摄政**。

你手里有一个由条约即将制造出来的国家、一支领不到军饷的军队、一部从未被实施过的宪法，
以及一个正在和贝尔格莱德谈判如何处置你的罗马政府。

## 快速开始

需要 Node.js 20 或更高版本。项目使用 React、TypeScript 与 Vite：

```bash
npm install
npm run dev                # Vite 开发服务
npm run build              # 生成 dist/
npm run preview            # 预览构建结果
```

**语言**：本作当前**只发布中文**。界面骨架字符串集中在 [`src/lib/i18n.js`](src/lib/i18n.js) 的 `I18N.STRINGS` 表；
游戏内容（事件、卡牌、法律、结局、顾问、地区……）在 `data/*.js` 中本身就是 `{ zh, it }` 节点结构，
由 `Core.L()` 按当前语言取值，`it` 同时充当历史语境的第二语言栏位。新增语言 = 在字符串表加一列 +
给内容节点加一个键（缺键自动回退中文）。切换入口是 `I18N.setLang('it')`，`I18N.LANGS` 里的占位条目
把 `enabled` 改成 `true` 即可出现在语言选择里。

**验证**

```bash
npm run lint               # TypeScript 检查
npm test                   # 引擎冒烟测试：完整对局 + 不变量 + 史实时点断言
npm run build && npm run verify:ui  # 无头 Chrome UI 验证与截图
```

## 玩法

**事件与议程。** 月初有必处理事件时直接打开决策；右侧议程显示本月待决事项。
顶栏的 `待决` 按钮可随时打开完整事件看板。
**事件处理完才能推进到下一月**。

报头下方有九个以 `tag_header.png` 装饰的标签：**事件、行动、地图、危机、经济、议会、外交、法律、人口**。
地图是默认视图；行动牌与顾问位于**行动**标签。

### 抽牌规则：点击牌堆即抽，牌堆是抽出来的不是挑出来的

| 模式 | 行为 |
| --- | --- |
| **史实 / 普通** | **点击牌堆直接抽一张**，卡牌立刻进入手牌槽位。没有选卡列表、没有中间弹窗。 |
| **沙盒** | 点击牌堆打开列表，指定要哪一张。 |

手牌槽位**始终可见**（含空位）：槽位行固定显示「预留处 1…4」四个格子，抽到的卡占据其中一个，空位显示为虚线格。
这样一眼就能看出还剩几个位置。

随机抽取使用引擎自带的**种子随机数**（`seed + turn×7919 + rngTick`），所以同一局同一回合的结果是**可复现**的——
读档重放不会出现不同的抽牌结果。

### 冷却：每张卡有独立的冷却时间

每张卡都有自己的冷却，分 **4 / 6 / 9** 三档（以「回合」计，一回合为半个月）：

| 档位 | 张数 | 用途 |
| --- | ---: | --- |
| **4** | 12 | 常规手段：宣传、酒馆、派系斗争、失业救济、照会、账本、劳动时间法与劳动保障法 |
| **6** | 10 | 重大立法与制度动作：自由港、市政警察改革、双语、大赦、公民身份、转口协定、阿伦戈、解除法西斯武装，以及进军线核心卡 |
| **9** | 4 | 改变局势的引擎：港口费与转口税（唯一永久抬高经常性收入）、金融军团（现金 +820）、乌斯科克（军械 +45）、军团招募（兵力 +1000） |

**冷却期间这张卡不会出现在牌堆里**——既不会被抽到，也不会被列出。冷却从**打出**的那一刻开始计
（不是结算选项时），冷却结束于 `monthIndex` 超过登记值。

行动卡 9 张、政府卡 17 张，共 26 张，全部带独立冷却。

> 原先还有一档 **3**（轻量小手段），只有《铁头》号外一张。该卡已移除（见下），
> 所以这一档目前没有成员——`W` 侧没有硬编码的档位清单，新卡若需要仍可用 3。

> **已移除的卡**：`az_molo`（到码头上去）、`az_cucine`（军团的伙房）、`az_volantini`（飞越亚得里亚海）、
> `az_arditi`（阿迪蒂集会）、`az_testa`（《铁头》号外）。
> 前两张的职能并入 `az_fiume_league` / `az_reclutamento`，空投传单并入 `az_propaganda` 第二选项。
> `az_testa` 的职能与 `az_propaganda` 的 `testa_di_ferro` 选项完全重合（资助卡利的《铁头》报，
> +5 未来主义 / +3 阿迪蒂），两张卡在争同一件事；`az_arditi` 的阅兵与代表大会已由
> `az_fazioni` 与 `az_cervo_doro` 覆盖。**这些 ID 不得复用。**

### 事件优先：待决事件会占满主区域

**有未处理的事件时，行动界面（牌堆、手牌、顾问）不再显示**，主区域被事件决策单完全占据。
理由很直接：事件未处理时 `ADVANCE` 本来就会被拒绝，行动标签页点了也走不下去，
让它们留在旁边只会让人以为这个月还能继续操作。事件处理完，行动界面自动回来。

沙盒模式与调试面板不受此限制。

开局可选政治力量目前只有**军团**（邓南遮）。**自治党与社会党已经建模但尚未开放**——
它们仍出现在选择界面上，显示为锁定（虚线框、灰度、「· 尚未开放」、🔒），点击不会改变选择。
只作为模拟势力存在的自治民主党、人民委员会、意大利国民委员会**不出现在选择界面**。
锁定由 `W.PARTIES[].player` 控制，引擎侧也做了兜底：向 `createState` 传一个锁定的 force 会回退到军团。

左侧保留邓南遮的大肖像，使用 `leader_frame.png` 肖像框与 `diplo_details_header` 纹样的浏览器版 PNG。
政党、阶层、派系、国家精神与历史记录集中在**人口**页；顾问位于**行动**。

| 面板 | 内容 |
| --- | --- |
| **事件** | 本月待决事件看板 |
| **行动** | 手牌（行动卡 / 政府卡）、顾问与本月简报 |
| **地图** | 阜姆领土图（13 个真实地区多边形），含城内武装驻点、围城圈、领土控制条 |
| **危机** | **两条独立危机轴**（围攻 / 党内）、各自的里程碑、力量对比与趋势 |
| **经济** | 港口吞吐、部门指标、收支、税率、资本信心 |
| **议会** | 制宪议会席位弧图、七位执政官、选举计票明细 |

### 两个危机，四条死因

游戏把「罗马要来打我」和「墨索里尼要来接管我」做成**两条独立累积的轴**，它们在**危机**页并列显示，
各有自己的里程碑文案：

| 轴 | 字段 | 由什么推动 | 满 100 触发 |
| --- | --- | --- | --- |
| **① 围攻 · 罗马的耐心** | `order.coup` | 紧张度 T（权威 / 驻军 / 热忱 / 法西斯暴力）、封锁、条约、合法性 | **血腥圣诞**（史实 1920-12） |
| **② 党内 · 法西斯的接管** | `order.subversion` | 法西斯小队、街头暴力、法西斯派在运动内的影响力 | **法西斯政变**（史实 1922-03） |

`subversionDelta = clamp[−6, 20]( −6 + 0.30×小队 + 0.35×max(0,暴力−25) + 0.50×max(0,法西斯派影响力−15) − 0.04×军团民意 )`

**关键**：内部轴不读 T、不读驻军、不读封锁——它只回答街头与党内。所以你可以被围攻几个月而不发生政变，
也可以在罗马还在谈判时就从内部被拿走。**这是史实结构**：阜姆先挡不住罗马，然后被自己的右翼接收。

四条死因因此是：

1. **血腥圣诞**（围攻轴满 100）。卡维利亚将军攻城，军团兵不够就守不住。
2. **法西斯夺权**（党内轴满 100）。君塔的小队从的里雅斯特进城，宪兵站在街角看着。
3. **《罗马条约》**（史实 1924-01-27）。什么都不做，罗马和贝尔格莱德会把你瓜分掉。
4. **无声的港口**。慢性的：吞吐上不去，人就走了。人口跌破 44 000，城市自己消失。

**14 种结局**，按四条战略路线（`route` 字段）归类：

| 路线 | 出口 |

| **并入意大利** `annexione` | 诗人离开 · 法西斯城邦 · 历史的结局 |
| **进军罗马** `marcia` | **进军罗马** · 长夜里的集会 |

例如：**卡尔纳罗共和国**（摄政活过 1926 年，成为一部被实施的宪章）、

**亚得里亚的但泽**（英法美共同保证，宪章在国联登记）、
**第二个威尼斯**（自由港三级 + 吞吐 ≥ 85 + 工团派 ≥ 20）、
**进军罗马**（凑齐三股力量与一支万人纵队，向南出发）、
**长夜里的集会**（被逐出省督府后，把一个运动维持下去）。

### 几个关键机制

**诗人不会算账。** 史实上，兼并列从 1919 年市政选举的压倒性多数，滑到 1921 年 4 月的 34%。
本作把这个过程做成一个每月结算的**社会支持流失**：封锁、欠饷、港口萧条，都会让店主、工人、
侨民从你这边流向扎内拉的自治党。合法性、实施宪章、劳动立法、语言条例都能减缓它。
**默认线（不干预）会精确复现史实**：1920 年 12 月血腥圣诞，1921 年 4 月失去议会多数
——游戏内推演**自治派阵营 57 席 / 兼并列阵营 19 席**，城区兼并列得票 **34.1%**（史实 34%）。

**制度陷阱。** 1921 年 4 月 24 日的选举法（第 1100 号）写成了兼并列：城区 68 席（51 多数 + 17 少数），
子市镇 8 席（6 多数 + 2 少数），得票第一的名单**通吃**多数派席位。默认是三份名单——
国民集团（LEG+ANI）、自治派（AUT+PAD+PCR）、社会党（PSI）。你也可以：
**加入国民集团**（默认）、**以军团兵名单单独参选**（`SPLIT_LISTS`，与国民党分道），
或者**干脆抵制**（`flags.boycott`）。三条路的席位数完全不同。

**五个派系——都在你的运动内部。** 派系不是全国政党，而是军团兵运动自己的路线斗争：

| 派系 | 领袖 | 初始影响力 / 异议 | 路线 |
| --- | --- | --- | --- |
| **阿迪蒂** Arditi | 马里奥·卡利 | 26 / 22 | 意大利阿迪蒂协会与《铁头》报。凯勒的飞机、维基的罗马支部。行动本身就是纲领。 |
| **工团派** Sindacalisti | 阿尔切斯特·德·安布里斯 | 24 / 16 | 工团法朗吉与《卡尔纳罗宪章》的起草者。要一部真的宪法。 |
| **未来主义派** Futuristi | 菲利波·托马索·马里内蒂 | 18 / 26 | 未来主义政治党。战争是卫生、速度是美、博物馆是坟墓。 |
| **法西斯派** Fascisti | 乔瓦尼·霍斯特-文图里 | 17 / 34 | 阜姆法西斯与的里雅斯特的君塔。他们要的是意大利，你只是踏脚石。 |
| **收复主义者** Irredentisti | 民族主义协会一翼 | 15 / 20 | 只要一件事：无条件并入意大利王国。 |

影响力总和 100，异议度各自独立；整体异议压低统一行动效率，顾问行动只受其**所属派系**的异议影响。

**两条硬性规则（引擎强制）：**

1. **影响力是零和转移，不是加减。** 影响力是「固定 100 的份额」，所以任何变化都从其他派系按
   **各自当前份额比例**扣除（或按比例分给它们）；某个派系不够扣时先扣到 0，余额继续分摊。
   唯一原语是 `R.adjustFactionInfluence(state, 目标派系, delta)`——**全仓没有第二处写 `inf` 的地方**。
   裸 `inf += x` 不是转移，它改变总额，随后的重标定会按大小从每个派系悄悄抽走一点。

2. **自动漂移必须挂在日志或法律上。** 引擎里**没有**任何无主的自动派系变化。
   目前唯一的自动漂移是 **`impresa` 日志的月度效果**：法西斯派 +0.125~0.275/月
   （血腥圣诞后 ×1.3，秩序法 ≥ 2 级再 ×1.2），阿迪蒂 / 工团派 / 未来主义派 / 收复主义者
   按 0.22 / 0.62 / 0.16 / 0.22 的比例让出——总和恰好为 0。日志面板会打印这条月度效果。
   **日志未激活或已完成时，它的效果不会执行**，所以漂移会随该日志一起结束。

   子整数变化会被保留（影响力内部是浮点，界面取整显示），否则 +0.125/月 会在每回合的取整里被抹掉。

**法西斯派的坐大**因此是可见的：它写在日志面板上，而不是藏在引擎里。
到 1922 年它会成为运动内最大的一派——这是史实：军团兵运动被它自己的右翼接收了。

**六个政党。** 1919–1924 年阜姆的政治光谱，而不是只有「你」和「敌人」：

| 阵营 | 政党 |
| --- | --- |
| 兼并（annessione） | `LEG` 军团（你）、`ANI` 意大利国民委员会（显示缩写 CNI） |
| 自治（autonomia） | `AUT` 自治党（扎内拉）、`PAD` 自治民主党、`PCR` 人民委员会 |
| 阶级（classe） | `PSI` 社会党 |

> **注**：`ANI` 这个 id 保留为内部键（选举名单、关系矩阵、议会轴与旧存档都用它），
> 改变的只是**显示名**——从「民族主义协会」改为「意大利国民委员会 / CNI」。
> 阜姆法西斯（`FAS`）在 1922 年 3 月政变之前**在制度上尚不存在**，因此不在政党表里；
> 它只作为派系与街头力量存在。

1921 年 4 月 24 日实际提交的是**三份名单**：国民集团（LEG+ANI）、自治派（AUT+PAD+PCR）、社会党（PSI）。
你可以共组国民集团、单独参选，或者干脆抵制。

**七位执政官。** 内阁就是史实的 `Consiglio dei Rettori`，掌握对应席位才能打出对应的政府卡：
外交、内政与司法、国防、财政、公共经济、劳动、教育。

**阶层支持度系统。** **七个**社会阶层，人口权重和为 100；每个阶层有一条**支持向量**分配给六个政党（行和 100）。
支持变化用零和算法执行。每个阶层还有一个特征：

| 特征 | 含义 |
| --- | --- |
| **投票率** turnout | 该阶层在选举中的参与度。有产精英 88%，子市镇克罗地亚农民 44% |

选举按 `列表支持度 × 阶层投票率 × (1 − 该党弃权率)` 结算，弃权传统记在 `W.PARTY_RULES`。
**社会党的弃权传统是 50%**——它抬高其他名单的有效票占比，这正是 1921 年 4 月自治党拿到压倒性多数的原因之一。

> **注**：早期设计里的「组织渗透 org」与「战斗性 militancy」已从模型中移除，
> 阶层现在只有 `pop / support / turnout` 三个字段。工会份额与土地、工业所有权饼图同样已移除。

**零和分布。** 阶层支持与派系影响力守恒。
「工人对军团兵支持 +3」、「工会份额 +2」、「工人接管工厂」在三件不同的事之间绝不自动换算。

## 架构约定

- **单一状态模型**：整个对局是**一个** JSON 可序列化的对象。
- **唯一写入漏斗**：UI 只发送 action → `Engine.dispatch` → 路由 → 领域规则 → `postProcess` 不变量管线。
- **内容层不导入 UI**：`action_affairs/*`、`government_affairs/*`、`party_affairs/*`、`advisors/*`、`events/*` 与 `engine/rules.js` 不引用 `document`，可在 Node 里直接跑。
- **事件链中间节点不可被调度**：`chain: true` 的节点只能通过父事件的 `next` / `queueEvents` 进入。
- **超级事件**（血腥圣诞、法西斯政变）由条件驱动，在 `pickEvent` 中享有最高优先级。
- **存档只保存纯数据与内容 ID**；函数在读取时经注册表恢复。

### 改内容时的注意点

1. **新增卡牌** — 在 `src/game/action_affairs`、`government_affairs` 或 `party_affairs` 中一卡一文件，并加入该目录的 `index.ts`。`effect` 用声明式补丁；`governo` 类要写 `ministry`（七个席位之一）。
2. **新增顾问** — 在 `src/game/advisors` 中一人一文件，并加入 `index.ts`。
3. **新增事件** — 在 `src/game/events` 中一事一文件，并加入 `index.ts`。`date` 可选；中间节点必须标 `chain: true`。然后跑 `node tools/smoke.js`。
4. **改史实校准** — `R.coupDelta` 与 `advanceMonth` 里的 `ero`（支持流失率）是为使血腥圣诞落在 1920 年 12 月、
   1921 年 4 月选举落在史实结果而调的。改完必须重跑冒烟测试第 4、5 项。
5. **改月度顺序** — `Eng.advanceMonth` 里的编号注释就是业务语义。

## 史实与推断

原始史料能支撑的部分都落实到具体日期、票数、人名与机构名称；无法直接证实的部分在
[`docs/历史考据.md`](docs/历史考据.md) 与游戏内「史料与致谢」里逐条标注为**推断**。两条最重要的：

> **1921 年制宪议会的席位分配是重建值。** 1921 年 4 月 24 日选举当天，法西斯与阿迪蒂分子袭击了上诉法院，
> 抢走并烧毁了票箱与选举文书，直接史料因此缺失。本作依据选举法（76 = 51+17+6+2）、多数制原则与得票率重建。

> **事态累积与支持流失的公式是为使史实线复现而校准的设计公式**，不是史料记载的量化模型。

## 已知边界

- 亚得里亚地图的国界是 Natural Earth 1:50m 的现代国界，**不是** 1920 年的边界。阜姆领土图则是基于
  现代地方委员会边界对 1921 年行政区划的**代理**——里耶卡在 1924 年后经历了意大利吞并、二战、
  1947 年并入南斯拉夫与战后重建，原始地籍边界已不可直接复用。
- 阶层人口权重是政治冲突的设计权重，不是人口学。
- 派系构成与初始影响力由军团兵运动的历史构成重构。
- 城市的街区控制度、动荡、失业率是设计值。

## 第二轮可以做什么

最自然的一步是**自治运动（Movimento Autonomista）**：它复用整个共同世界（阶层、选举、经济、法律、地图、外交），
只需替换 `PlayerForce` 配置——初始支持矩阵、组织目录、内部派系、顾问池、卡牌目录、政府参与权限、
法律立场与结局评价表。它的玩法轴正好相反：在议会里守住 57 席，在街头用法律和警察对抗军团兵与法西斯。

1924 年 2 月 22 日，阜姆自由邦失去了它的领土。扎内拉的流亡议会一直开到 1950 年代；
邓南遮在加尔达湖畔写到 1938 年去世，从未承认 1920 年 12 月的那件事已经结束。

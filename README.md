# Fiume o morte! · 意大利卡尔纳罗摄政 1919

一个关于 1919–1924 年**阜姆**（Fiume / Rijeka）的历史政治模拟游戏。

你是**加布里埃莱·邓南遮**——「指挥官」（Il Comandante）。1919 年 9 月 12 日，你带着两千五百名军团兵从 Ronchi
走进这座城市。1920 年 9 月 8 日，你在省督府的阳台上颁布《卡尔纳罗宪章》，宣布成立**意大利卡尔纳罗摄政**。

你手里有一个由条约即将制造出来的国家、一支领不到军饷的军队、一部从未被实施过的宪法，
以及一个正在和贝尔格莱德谈判如何处置你的罗马政府。

## 快速开始

需要 Node.js 20 或更高版本。项目使用 React、TypeScript 与 Vite：

```bash
npm install
npm run dev                # Vite 开发服务
npm run build              # 生成 dist/
npm run preview            # 预览构建结果
```

**语言**：本作当前**只发布中文**。界面骨架字符串集中在 [`src/lib/i18n.js`](src/lib/i18n.js) 的 `I18N.STRINGS` 表；
游戏内容（事件、卡牌、法律、结局、顾问、地区……）在 `data/*.js` 中本身就是 `{ zh, it }` 节点结构，
由 `Core.L()` 按当前语言取值，`it` 同时充当历史语境的第二语言栏位。新增语言 = 在字符串表加一列 +
给内容节点加一个键（缺键自动回退中文）。切换入口是 `I18N.setLang('it')`，`I18N.LANGS` 里的占位条目
把 `enabled` 改成 `true` 即可出现在语言选择里。

**验证**

```bash
npm run lint               # TypeScript 检查
npm test                   # 引擎冒烟测试：完整对局 + 不变量 + 史实时点断言
npm run build && npm run verify:ui  # 无头 Chrome UI 验证与截图
```

## 玩法

**事件与议程。** 月初有必处理事件时直接打开决策；右侧议程显示本月待决事项。
顶栏的 `待决` 按钮可随时打开完整事件看板。
**事件处理完才能推进到下一月**。

报头下方有七个以 `tag_header.png` 装饰的标签：**地图、危机、经济、议会、外交、法律、档案**。地图是默认视图；行动牌入口位于顶栏。

开局可选政治力量为**军团、自治党、社会党**，各有党徽、领袖资料和开场事件。其余政党仍作为模拟中的政治势力存在。

左侧保留邓南遮的大肖像，使用 `leader_frame.png` 肖像框与 `diplo_details_header` 纹样的浏览器版 PNG。
政党、阶层、派系、国家精神与历史记录集中在**档案**；顾问位于**行动**。

| 面板 | 内容 |
| --- | --- |
| **地图** | 阜姆领土图（13 个真实地区多边形），含城内武装驻点、围城圈、领土控制条 |
| **经济** | 港口吞吐、部门指标、收支、税率、工会与所有权 |
| **行动** | 手牌（行动卡 / 政府卡 / 党卡）、顾问与本月简报 |
| **议会** | 制宪议会席位弧图、七位执政官、选举计票明细 |
| **外交** | 九国外交关系、四种外交姿态、税务与关税 |
| **法律** | 十二条法律与各党立场分值 |
| **事态** | 危机量表、里程碑、力量对比与趋势 |
| **档案** | 政党与阶层民意、派系、社会矩阵、日志和史实时间轴 |

### 顶部资源栏

| 格 | 含义 |
| --- | --- |
| **金库** Tesoro | 摄政的现金（M£）。军团军饷是最大一笔支出；贴现银行印的阜姆券是第二条命脉 |
| **合法性** Legittimità | 条约、宪章与议会给你的权威 |
| **军团兵力** Milizia | 你实际能拿枪的人数。攻击省督府时，这个数字决定你能不能守住楼梯 |
| **事态** Crisi | 达到阈值时可能触发城内外危机 |
| **本月行动** AP | 本月剩余行动点 |

金库、合法性与军团兵力显示相对上月的变化；事态与行动点显示当前值。

### 四条死因

1. **血腥圣诞**（史实：1920 年 12 月 24 日）。四条量表派生出紧张度 T，T 派生出每月的事态累积 Δ。
   到 100 时卡维利亚将军攻城。军团兵不够，你就守不住。
2. **法西斯夺权**（史实：1922 年）。血腥圣诞之后事态重新累积，这一次是君塔的小队。
3. **《罗马条约》**（史实：1924 年 1 月 27 日）。什么都不做，罗马和贝尔格莱德会把你瓜分掉。
4. **无声的港口**。慢性的：吞吐上不去，人就走了。人口跌破 44 000，城市自己消失。

### 你会赢在哪

13 种结局。例如：

- **卡尔纳罗共和国** —— 摄政活过 1926 年，成为一部被实施的宪章
- **阜姆公社** —— 法团院真的开会，劳动写进第一条，工厂归合作社
- **亚得里亚的但泽** —— 英法美共同保证，宪章在国联登记
- **第二个威尼斯** —— 自由港三级 + 吞吐 ≥ 85 + 本地人重新掌权
- **长夜里的集会** —— 被逐出省督府后，把一个运动维持下去

### 几个关键机制

**诗人不会算账。** 史实上，兼并列从 1919 年市政选举的压倒性多数，滑到 1921 年 4 月的 34%。
本作把这个过程做成一个每月结算的**社会支持流失**：封锁、欠饷、港口萧条，都会让店主、工人、
侨民从你这边流向扎内拉的自治党。合法性、实施宪章、劳动立法、语言条例都能减缓它。
**默认线（不干预）会精确复现史实**：1920 年 12 月血腥圣诞，1921 年 4 月失去议会多数
——游戏内推演**自治派阵营 57 席 / 兼并列阵营 19 席**，城区兼并列得票 **34.1%**（史实 34%）。

**制度陷阱。** 1921 年 4 月 24 日的选举法（第 1100 号）是兼并列写的：城区 68 席（51 多数 + 17 少数），
子市镇 8 席（6 多数 + 2 少数），得票第一的名单**通吃**多数派席位。你可以与法西斯共组「国民集团」名单，
也可以单独参选（法西斯另立名单），或者干脆抵制。三条路的后果完全不同。

**四个派系——都在你的运动内部。** 派系不是全国政党，而是军团兵运动自己的路线斗争：

| 派系 | 领袖 | 初始影响力 / 异议 | 路线 |
| --- | --- | --- | --- |
| **阿迪蒂** Arditi | 马里奥·卡利 | 30 / 22 | 意大利阿迪蒂协会与《铁头》报。凯勒的飞机、维基的罗马支部。行动本身就是纲领。 |
| **工团派** Sindacalisti | 阿尔切斯特·德·安布里斯 | 28 / 16 | 工团法朗吉与《卡尔纳罗宪章》的起草者。要一部真的宪法。 |
| **未来主义派** Futuristi | 菲利波·托马索·马里内蒂 | 22 / 26 | 未来主义政治党。战争是卫生、速度是美、博物馆是坟墓。 |
| **法西斯派** Fascisti | 乔瓦尼·霍斯特-文图里 | 20 / 34 | 阜姆法西斯与的里雅斯特的君塔。他们要的是意大利，你只是踏脚石。 |

影响力总和 100，异议度各自独立；整体异议压低统一行动效率，顾问行动只受其**所属派系**的异议影响。
**法西斯派的影响力每月自动增长**（蜜月期 +0.25，血腥圣诞之后 +0.55 并再乘 1.3）——到 1922 年它会成为
运动内最大的一派。这是史实：军团兵运动被它自己的右翼接收了。

**十个政党。** 1919–1924 年阜姆的完整政治光谱，而不是只有「你」和「敌人」：

| 阵营 | 政党 |
| --- | --- |
| 兼并（annessione） | `LEG` 军团兵·卡尔纳罗（你）、`FAS` 阜姆法西斯、`ANI` 民族主义协会、`LIB` 自由党 |
| 自治（autonomia） | `AUT` 自治党（扎内拉）、`PAD` 自治民主党、`PCR` 克罗地亚党、`PPI` 意大利人民党 |
| 阶级（classe） | `PSI` 社会党、`PCF` 阜姆共产党 |

1921 年 4 月 24 日实际提交的是**四份名单**：国民集团（LEG+FAS+ANI+LIB）、自治派（AUT+PAD+PCR+PPI）、
社会党、阜姆共产党。你可以共组国民集团、单独参选（法西斯另立名单），或者干脆抵制。

**七位执政官。** 内阁就是史实的 `Consiglio dei Rettori`：邓南遮（外交）、Icilio Bacci（内政与司法）、
Host-Venturi（国防）、Maffeo Pantaleoni（财政）、Luigi Bescocca（公共经济）、Clemente Marassi（劳动）、
Lionello Lenaz（教育）。掌握对应席位才能打出对应的政府卡。

**阶层支持度系统。** 九个社会阶层，人口权重和为 100；每个阶层有一条**支持向量**分配给十个政党（行和 100）。
支持变化用零和算法执行。每个阶层还有三条独立特征：

| 特征 | 含义 |
| --- | --- |
| **投票率** turnout | 该阶层在选举中的参与度。地主食利者 92%，子市镇克罗地亚农民 44% |
| **组织渗透** org | 被工会与协会组织起来的程度。由工会份额、组织成立状态与街头暴力派生，逐月向目标值收敛 |
| **战斗性** militancy | 罢工与示威的倾向。由组织度 + 罢工强度 + 失业 + 通胀派生 |

选举按 `列表支持度 × 阶层投票率 × (1 − 该党弃权率)` 结算。**社会党的弃权传统是 50%**——
它抬高其他名单的有效票占比，这正是 1921 年 4 月自治党拿到 66% 的原因之一。

**零和分布。** 阶层支持、派系影响力、工会份额、土地与工业所有权饼图全部守恒。
"工人对军团兵支持 +3"、"工会份额 +2"、"工人接管工厂"是三件不同的事，绝不自动换算。

## 架构约定

- **单一状态模型**：整个对局是**一个** JSON 可序列化的对象。
- **唯一写入漏斗**：UI 只发送 action → `Engine.dispatch` → 路由 → 领域规则 → `postProcess` 不变量管线。
- **内容层不导入 UI**：`action_affairs/*`、`government_affairs/*`、`party_affairs/*`、`advisors/*`、`events/*` 与 `engine/rules.js` 不引用 `document`，可在 Node 里直接跑。
- **事件链中间节点不可被调度**：`chain: true` 的节点只能通过父事件的 `next` / `queueEvents` 进入。
- **超级事件**（血腥圣诞、法西斯政变）由条件驱动，在 `pickEvent` 中享有最高优先级。
- **存档只保存纯数据与内容 ID**；函数在读取时经注册表恢复。

### 改内容时的注意点

1. **新增卡牌** — 在 `src/game/action_affairs`、`government_affairs` 或 `party_affairs` 中一卡一文件，并加入该目录的 `index.ts`。`effect` 用声明式补丁；`governo` 类要写 `ministry`（七个席位之一）。
2. **新增顾问** — 在 `src/game/advisors` 中一人一文件，并加入 `index.ts`。
3. **新增事件** — 在 `src/game/events` 中一事一文件，并加入 `index.ts`。`date` 可选；中间节点必须标 `chain: true`。然后跑 `node tools/smoke.js`。
4. **改史实校准** — `R.coupDelta` 与 `advanceMonth` 里的 `ero`（支持流失率）是为使血腥圣诞落在 1920 年 12 月、
   1921 年 4 月选举落在史实结果而调的。改完必须重跑冒烟测试第 4、5 项。
5. **改月度顺序** — `Eng.advanceMonth` 里的编号注释就是业务语义。

## 已知边界

- 亚得里亚地图的国界是 Natural Earth 1:50m 的现代国界，**不是** 1920 年的边界。阜姆领土图则是基于
  现代地方委员会边界对 1921 年行政区划的**代理**——里耶卡在 1924 年后经历了意大利吞并、二战、
  1947 年并入南斯拉夫与战后重建，原始地籍边界已不可直接复用。
- 阶层人口权重是政治冲突的设计权重，不是人口学。
- 派系构成与初始影响力由军团兵运动的历史构成重构。
- 城市的街区控制度、动荡、失业率是设计值。

## 第二轮可以做什么

最自然的一步是**自治运动（Movimento Autonomista）**：它复用整个共同世界（阶层、选举、经济、法律、地图、外交），
只需替换 `PlayerForce` 配置——初始支持矩阵、组织目录、内部派系、顾问池、卡牌目录、政府参与权限、
法律立场与结局评价表。它的玩法轴正好相反：在议会里守住 57 席，在街头用法律和警察对抗军团兵与法西斯。

1924 年 2 月 22 日，阜姆自由邦失去了它的领土。扎内拉的流亡议会一直开到 1950 年代；
邓南遮在加尔达湖畔写到 1938 年去世，从未承认 1920 年 12 月的那件事已经结束。

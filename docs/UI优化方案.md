# 《FIUME O MORTE!》UI 优化方案

> 2026-09-29 执行修订：按最新要求保留邓南遮常驻大肖像，并使用 `leader_frame.png`、`diplo_details_header`。肖像和相关资源位于 `public/img/Portrait`、`public/img/UI`。

## 目标与判断依据

本方案基于 2026-09-29 的 `build_ui/` 截图、原视图代码及现有样式。当前项目已迁入 React/Vite，目录与依赖方向以根目录 `ARCHITECTURE.md` 为准。目标是让玩家在进入每个月时迅速看清**局势、待决事项、可采取的行动、行动代价**，同时保留深层政治模拟的数据可查性。

现状有鲜明的黑金深红、历史照片、徽章和地图，主题辨识度已经具备。主要问题是信息常驻过多：顶栏六项资源、七枚页签、左右两条长栏、地图下方六张地区卡和底部日志同时出现。相同指标与名单还分散在多个面板，玩家需要阅读许多材料才能找到本月的决策。

### 设计准则

1. **一屏一个主问题**：默认画面回答“本月最紧迫的事是什么”；详细数据按需展开。
2. **一个信息有一个主位置**：其他位置只给摘要和跳转，避免并列的完整副本。
3. **视觉强度跟随决策等级**：深红只用于关键选择和真实警报；金色用于选中和强调；日常数据安静呈现。
4. **历史气质由排版和仪式感承担**：公报、誓词、肖像、海港、地图、印章构成视觉语言。可操作文字必须清楚易读。
5. **保留复杂度，降低初次暴露量**：十党、九阶层、十二条法律、公式和史料仍可查看，但不占据默认视野。

## 邓南遮美学如何转成界面

可以用两种相连的场景构成整体气质：黑色舞台上的宣告，以及浅色纸张上的政令。邓南遮在维托里亚莱的居室运用昏暗光线、帷幔、器物和题词营造象征氛围；1920 年阜姆《卡尔纳罗宪章》正式文本的公报封面则是浅底、黑字、细框、居中标题。前者适合首页、结局和重大事件，后者适合需要仔细阅读的政务、经济和法律。维托里亚莱的许多陈设属于 1921 年以后，作为邓南遮个人审美参考使用；1919–1920 年的具体视觉复原优先参考阜姆当时的公报、印刷品和照片。[维托里亚莱故居介绍](https://www.vittoriale.it/en/il-vittoriale-its-sites/the-priory/)；[阜姆史料与公报图录，第 40 页](https://www.arengario.it/wp-content/uploads/2019/10/arengario-2019-guida-mostra-vittoriale-web.pdf)。

建议确立以下视觉规则：

| 元素 | 建议 | 用途 |
| --- | --- | --- |
| 底色 | 暖黑 `#120F0C`、纸色 `#E8DDC3` | 黑色用于导航与戏剧性页面；纸色用于长文和数据表 |
| 文字 | 纸面深墨 `#252017`、暗面暖白 `#F0E7D4` | 正文优先确保清晰，次要文字也保持可读 |
| 强调 | 暗红 `#8C262B`、旧金 `#B69347`、海蓝 `#31566B` | 红色限于关键决策/危险，金色限于焦点，蓝色给地图与外交 |
| 字体 | 意大利文大标题用 Cinzel/衬线；中文标题用宋体；正文用清晰的中文正文字体；数值用等宽数字 | 拉丁字装饰不能代替中文可读性 |
| 边框 | 每个主要区块一条细线，重要弹窗可用双线 | 取消每张小卡的双框与每段内容的分隔花饰 |
| 图像 | 首页和大事件使用史料照片；局内保留邓南遮大肖像并以原纹样装框 | 肖像作为固定叙事锚点，其余人物肖像按需出现 |
| 图标 | 罗盘、锚、文书、天平、钟、月桂等简单单色图形 | 一个概念固定一个图形；历史特定符号只在相关史料语境使用 |

减少两侧固定装饰柱、每栏红色楣条、反复出现的星号和渐变。格言只保留在首页、月初大事件或结局处。局内常规界面应有更强的留白和节奏，仪式感才会在重要时刻真正显现。

## 新的信息架构

> 2026-09-29 后续实现：游戏内导航改为地图、危机、经济、议会、外交、法律、档案七个独立标签，以 `tag_header.png` 为底；行动页入口移至顶栏。开局只显示军团、自治党和社会党，并附党徽。下表保留最初的四入口草案，供设计沿革参考。

最初规划将顶层七个圆章改成四个有文字的导航项：

| 一级入口 | 默认呈现 | 进入后可查 |
| --- | --- | --- |
| **局势** | 阜姆地图、当前危机、关键变化 | 地区详情、军力、社会走势、危机里程碑 |
| **行动** | 当前手牌、可抽牌堆、本月 AP | 顾问任免与行动、卡牌详情与效果预览 |
| **政务** | 最近使用的政务页 | 经济、制度（议会与法律）、外交 |
| **档案** | 本局时间线 | 事件记录、史实说明、成就、统计与完整社会矩阵 |

固定顶栏只显示日期、金库、合法性、军团兵力、事态进度、剩余 AP，以及“待决 N 项”。工业生产、民众热忱、外交压力等仍可从对应页面和顶栏展开层查看。趋势箭头只在数值发生有意义的变化时出现，并标明比较周期。

桌面默认采用**指挥官肖像 + 主内容 + 本月议程**三列。肖像栏约 215–250px，只保留身份、两项人物状态和存档入口；主内容占据剩余空间；议程约 250–292px。宽度低于约 1080px 时改为两列，议程置于主内容上方；小屏幕改为单列，依次呈现肖像、议程和主内容。

```text
┌ 日期 ─ 金库 ─ 合法性 ─ 兵力 ─ 事态 ─ AP ─ 待决 2 ─ 设置 ┐
│  局势             行动             政务             档案  │
├───────────┬───────────────────────────┬──────────────────┤
│ 邓南遮肖像 │ 当前主画面：地图 / 行动 / 政务 │ 本月议程         │
│ 身份与状态 │ 点选对象后出现就地详情        │ 待决事项与推进   │
└───────────┴───────────────────────────┴──────────────────┘
```

## 明确删减与归位清单

| 左栏十党逐项、九阶层三条量表 | 默认显示联盟/反对派摘要；完整名单进“档案→社会” | 保留模拟深度，减少默认阅读负担 |

| 右栏事件清单、事件看板弹窗 | 议程展示当前及排队事件；已处理事件折叠 | 同一月的事件只出现一份完整列表 |
| 右栏日志、底部滚动日志 | 合并为“档案→事件记录”；重要变化以一次性提示呈现 | 避免同一记录重复出现 |
| 地图下方固定六张地区卡 | 改为点选地区后的详情栏/浮层 | 地图本身已经是地区索引 |
| 经济页“全国支持”与左栏政党支持 | 经济页移除完整党表，只保留经济影响摘要 | 全国支持统一归“社会” |
| 外交页九国关系条和下方“主要对手”列表 | 合并为一张可展开的关系列表 | 同一数值只显示一次 |
| 事态页正文中的两条计算公式 | 移到“机制说明”展开项 | 主画面显示下月趋势、来源和阈值 |

## 关键页面改造

### 1. 开始界面

保留一个大标题、一幅主照片、三至五句背景，以及明确的“开始”按钮。当前固定的政治主体和唯一剧本不再做成选择卡；难度用一行单选项呈现，选择时显示 AP/手牌/事态差异。史实与致谢在开始前可进入“资料”，游戏里从设置继续进入。

### 2. 局势与地图

地图做主视觉。上方只放“事态 8/100、预计下月变化、最迫近的威胁”三项。地图上的军力符号按需切换，图例默认简短，支持“领土 / 武装 / 民意”视图切换。点选地区后显示控制、动荡、变化原因、相关行动入口；关闭后恢复大地图。地图上的引文可在章节切换时出现，常规地图视图不常驻覆盖文字。

### 3. 本月议程与事件

月初如有必处理事件，议程自动聚焦第一项；叙事正文与 2–3 个选择在专注的决策弹窗中展示。每项选择统一呈现“做什么、立即代价、可预见后果、不可用原因”。事件看板顶部显示“待处理 2/4”；已处理项汇总为可展开的一行。待决未清时推进按钮显示明确阻止原因。事件全部处理后，议程展示剩余 AP 和本月可用行动，再给“推进下月”。

### 4. 行动

上方三个牌堆保持；手牌成为页面主体，卡片只展示标题、类型、成本、一句作用。点开卡牌再阅读局势文本和选项。空手牌位不绘制四张空卡，可用“手牌 2/4”与“抽取”承载。顾问放在同页次级区域；有可执行顾问行动时在手牌旁显示一个简洁提示。

### 5. 政务

**经济**：首屏先给港口吞吐、收支、失业与人口四个结果，再放可操作的税率与预计收支变化；所有权饼图、工会明细和阶层矩阵进入详细层。**制度**：未选举时用简短说明加下次选举日期替代大面积空图；法律按主题分组，显示当前等级与下一步政策入口。**外交**：一个关系列表配当前外交姿态；选择新姿态前给出消耗、可预见收益和主要风险。

### 6. 档案与结局

档案汇总事件、历史时间轴、社会矩阵、成就和机制说明，提供筛选或分组。结局页保留大标题与叙事段落，统计精选 3–4 项能解释本局结局的指标，其余进入“本局完整报告”；成就显示新增获得的项目，避免十八张卡片与结局争夺焦点。

## 交互、排版与可用性标准

- 正文字号以 15–16px 为基准；辅助说明尽量不低于 12px。当前许多 9–11px 的中文标签需要提升。
- 中文正文控制每行约 30–45 个汉字；意大利文作为标题注脚或史料信息，避免每个按钮都双语占位。
- 按钮状态至少有文字/形状差异，警报不能只靠红绿颜色辨认。关键操作的可点击区域在触屏上达到约 44px。
- 为导航、地图地区、卡牌和弹窗提供键盘焦点样式；地图地区需要可聚焦、可读名称。弹窗打开后焦点进入，关闭后回到触发按钮。
- 保留轻微纸张纹理，但减弱正文底下的条纹和噪声；长文用纸色面板与深色文字。
- 动画限定在事件入场、选中反馈和数值变化；支持减少动态效果。不要让持续闪烁承担警报功能。
- 高风险决定在选择前展示后果；存档覆盖、弃牌、推进月份的反馈必须明确。

## 实施顺序与验收

| 阶段 | 范围 | 验收方式 |
| --- | --- | --- |
| P0 可读性与显见错误 | 增大正文/辅助字、补焦点状态；修正事态页工业/外交条的 `NaN`、读档后落入错误页签等显示问题 | 1680、1280、960、390px 截图与键盘走查；数值不出现 `NaN` |
| P1 去重与首屏 | 保留肖像并收起左栏社会长表、合并事件列表与日志、地图地区改点选详情；顶栏和导航重排 | 进入对局后首屏能看到主要局势和待决事件；无待决时能直接推进 |
| P2 页面重组 | 政务/档案分层；行动与顾问合并；法律/外交折叠详情 | 完整数据仍可在两次导航内找到；每项决策能看见成本与后果 |
| P3 视觉定型 | 公报纸面、标题字阶、照片使用、图标统一、简化装饰 | 首页、普通月份、重大事件、结局四类截图形成统一且有强弱层次的风格 |

以一局从 1919 年开局推进到 1920 年末的操作走查验收：玩家能找到每项必处理事件、用卡与顾问、调整税率与外交姿态、检查制度状态、保存及读档。每次进入新月份，主要行动无需在左右长栏中搜寻。

- `tools/verify_ui.js`：四类关键状态及不同宽度的截图验证。

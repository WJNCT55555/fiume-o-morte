## 0. 设计目标

### 三副卡的分工

参照 `cnt-fai` 的三族划分与 `SDAAH` 的 `party_affairs` 场景分类，本作按**行动主体**而非政策领域划分：

| 副 | 主体 | 回答的问题 | 必有的效果维度 |
| --- | --- | --- | --- |
| **行动卡** `azione` | 运动本身 | 本周我们把力气花在哪？ | 阶层支持 / 资源 / 秩序 |
| **政府卡** `governo` | 执政官席位 | 国家机器做什么？ | 法律 / 外交 / 经济 / 制度 |
| **党卡** `partito` | 军团兵运动的内部路线 | 我们是谁？ | **派系影响力与异议（必有）** |

**判据**：一张卡如果完全不动派系，它就不该是党卡。一张卡如果不需要执政官席位，它就不该是政府卡。

### 目标比例

| 副 | 现有 | 目标 | 说明 |
| --- | --- | --- | --- |
| 行动卡 | 14 | **20** | 每月手牌 4 张、牌库越大越有重开价值 |
| 政府卡 | 16 | **20** | 七个席位各 2–3 张 |
| 党卡 | 7 | **12** | 四个派系各 3 张 |
| 合计 | 37 | **52** | |

### 派系覆盖矩阵（党卡的硬约束）

| 派系 | 现有党卡 | 目标 |
| --- | --- | --- |
| 阿迪蒂 `arditi` | `pt_arditi` `pt_tetti` | **3** |
| 工团派 `sindacalisti` | `pt_falange` `pt_carnaro` | **3** |
| 未来主义派 `futuristi` | — | **3** |
| 法西斯派 `fascisti` | `pt_fascio` | **3** |

**未来主义派目前零张党卡**——这是最明显的缺口。

### 关于 `pt_fiumani`

`pt_fiumani` 是**派系重构前的遗留命名**。它现在的效果是阶层支持（自治阵营 −），
方向正确，但 ID 里的 `fiumani` 对应一个已删除的派系。建议改名为 **`pt_citta`**
（把城里的人拉进来），并按 skill 的规定走 `support` 而非 `factions`。

> ID 改名会影响存档。改名时需在 `Eng.loadGame` 的迁移表里加一条映射，或接受旧存档失效。

## 4. 实施顺序

按「补缺口 → 加厚度」排：

1. **`pt_marinetti` / `pt_manifesto` / `pt_avanguardia`** — 未来主义派零党卡，最刺眼的缺口
2. **`az_futuristi`** — 未来主义派连一张行动卡都没有
3. **`gv_salari` / `gv_coop`** — 劳动席位只有一张，且是失业救济（经济卡而非劳动卡）
4. **`pt_sindacato` / `pt_legione_party`** — 工团派第三条路线与「运动政党化」这条真实史实分支
5. **`gv_scuola` / `gv_belgrado`** — 教育只有一张；外交缺对南斯拉夫的双边条约
6. **`pt_fiumani` → `pt_citta` 改名** + 存档迁移
7. **`az_battaglione` / `az_sussak` / `az_duomo` / `az_irredenti` / `az_plebiscito`**

每完成一批：

```powershell
node tools/smoke.js        # 随机打牌，验证不变量不被打破
node tools/verify_ui.js    # 逐页签渲染 + 打到结局
```

# 经济模型与指标审计

依据当前游戏代码（`src/game/engine/rules.js`、`reducers.js`、`meta.js` 及卡牌/事件目录）。每个回合为半个月。下文的 `clamp(x,a,b)` 表示把 `x` 限制在 `a` 与 `b` 之间；公式用结算前的当前状态求值，随后按顺序更新，所以同一回合的失业目标会读到**已更新**的港口吞吐。

## 计算公式

1. **港口吞吐目标** = `clamp(11 + 0.32×腹地通达 + 5×自由港法等级 + 0.17×三角洲控制 + 0.13×港口工程 + 0.12×国际承认 − 0.20×政治暴力 − 0.10×罢工强度, 0, 100)`；新吞吐 = 旧吞吐 + `0.09×(目标−旧吞吐)`。
2. **工业活跃度** = `clamp(0.60×港口工程 + 0.40×(100−罢工强度), 0, 100)`。这只是失业公式的中间量，没有独立库存或危机读数。
3. **失业目标** = `clamp(46 − 0.42×当前吞吐 − 0.12×工业活跃度, 4, 45)`；新失业 = 旧失业 + `0.125×(目标−旧失业)`。
4. **通胀目标** = `clamp(4 + 0.25×max(失业−12,0) + 0.12×罢工 + 0.004×max(债务−2500,0), 1, 55)`；新通胀 = 旧通胀 + `0.10×(目标−旧通胀)`。
5. **资本信心目标** = `clamp(70 − 0.50×罢工 + 0.25×(吞吐−40) − 0.30×暴力 + 0.20×合法性, 0, 100)`；新信心 = 旧信心 + `0.075×(目标−旧信心)`。结算时，债务不足 6500 且发生赤字还会先扣 `0.4` 信心；之后应用自由港法每级 `+1.2`、财政法每级 `−0.9` 的半月效果。
6. **迁出人数** = `clamp(20×(失业−12) + 4×(暴力−40), 0, 900)`；新人口 = `max(30000, 旧人口−迁出人数+30)`。事件、卡牌可额外直接改变人口。

四项收入（单位 K£，均为每半月）分别为：

所得税**有效税率**：财政法低于 2 级时为 0；2 级为 `max(设定税率,0.30)`；3 级为 `max(设定税率,0.45)`。这使「累进所得税」和「直接税 + 关税组合」真正产生所得税收入。

```text
港口费 = 吞吐×3.1×港口税率×(0.75+0.005×资本信心)×(1+港口增收修正)
关税   = 吞吐×2.5×关税率×(1+0.05×关税法等级)×(1+关税增收修正)
消费税 = (100−失业)×0.45×消费税率×(1+消费税增收修正)
所得税 = (100−失业)×0.70×有效所得税率×(1+0.04×财政法等级)×(1+所得税增收修正)
```

六项支出为行政 `42`、市警 `6+警员/40`、军团 `人数×0.013`、工程 `工程指数/100×12`、债务利息 `债务×0.0035`、救济 `max(失业−12,0)×1.7 + 劳动保障等级×2`。结余 = 四项收入之和 − 六项支出之和。先把结余计入经费（经费最低为零）；盈余时最多拿结余的 50% 偿债。赤字时先用经济储备，之后若债务尚小于 6500，就增加 `剩余赤字×1.15` 的债务；否则把剩余赤字记入欠款并扣领袖权威 `0.8`。财政结算发生在港口/失业/通胀更新之前。

## 用途检查

| 指标 | 参与后续游戏计算 | 事件/选项的直接门槛 | 被事件/选项直接改动 | 成就、日志、结局 |
|---|---|---|---|---|
| 港口吞吐 | 收入、失业、信心、选区控制、联盟凝聚及阶层支持漂移 | 白头事件：吞吐 `<60` | 多张港口、封锁、金融等卡牌/事件 | 港口复兴日志 `≥75`；「港口回来了」成就 `≥75`；「第二个威尼斯」「阜姆或死亡！」结局 `≥85` |
| 腹地通达 | 吞吐目标 | 无直接门槛 | 海关协定、港口工程、巴罗斯等 | 间接影响港口条件 |
| 三角洲控制 | 吞吐目标 | 巴罗斯谈判事件 `<45` | 巴罗斯谈判、南斯拉夫海关卡牌 | 间接影响港口条件 |
| 港口工程 | 吞吐目标、工业活跃度、工程支出 | 无直接门槛 | 港口建设等卡牌、港口复兴日志 | 间接影响港口条件 |
| 国际承认 | 吞吐目标 | 无直接门槛 | 外交事件和新闻卡牌 | 间接影响港口条件 |
| 罢工强度 | 吞吐目标、工业活跃度、通胀、信心及累计罢工次数 | 罢工事件 `<42` | 劳工事件、卡牌 | 间接影响经济与政治结果 |
| 资本信心 | 港口费收入、下轮信心目标 | 无直接门槛 | 财政、港口、劳工等选项及日志 | 通过财政和就业间接影响 |
| 失业率 | 消费/所得税、救济、通胀、迁出、区域骚动、阶层支持 | 工厂事件 `>24` | 失业救济等卡牌/事件 | 通过人口、财政间接影响 |
| 通胀率 | 阶层支持漂移 | 无直接门槛 | 债券、财政和日志效果 | 阜姆券日志成功 `<12`、失败 `>45`；「不印钞的政府」成就 `<12` 且债务 `<1800` |
| 人口 | 每轮人口增减、人口流失累计 | 无直接门槛 | 公民身份、暴力事件、日志等 | 「一千个空房子」成就累计流失 `≥5000`；「无声的港口」结局人口 `<44000` |
| 债务 | 利息、通胀、赤字融资门槛 | 无直接门槛 | 金融/预算卡牌 | 阜姆券日志和「不印钞的政府」成就 `<1800` |
| 经费 | 卡牌支付、可用性及招聘 | 多张卡牌有经费要求 | 广泛的卡牌/事件 | 通过军团与结算间接影响 |
| 半月总收入 `lastRevenue` | 军团兵自动征募量 | 无 | 半月结算写入 | 通过兵力间接影响 |

**未形成独立玩法回路的字段：**`economy.treasury` 初始为零，现有已编写的事件/卡牌没有增加它；赤字结算会读取并消耗它，因此它不是纯展示字段，但正常对局没有来源。`economy.arrears` 会在债务达到 6500 后累积，累积数字没有被后续公式、选项条件、成就或结局读取；发生欠款时的权威惩罚由当期赤字分支直接触发。界面因此不再常驻显示零储备，只在欠款大于零时显示欠款。

**已修正的无效效果：**「港口费与转口税」卡牌的大幅征收选项原会写入 `revenueBoost.dogana = +0.10`，收入计算却只读取港口费的修正。现在关税、消费税、所得税各自的增收修正均进入对应收入公式；卡牌预览也改为分项表述。`economy.lastSpending` 与 `economy.lastNet` 原来只被存储（后者还被 selector 读取但未渲染），未被结算或判定使用，已从新状态和第 10 版存档迁移中移除；实时支出与结余由收入/支出函数计算。

**已接通的税种：**普通对局没有调税按钮，初始所得税率为零；以前即使把财政法升至 2/3 级，所得税仍为零。现在财政法达到 2 级即开征、3 级提高基础税率，同时保留显式调税值高于基础值时的作用。

## 1. 一句话概念与设计原则

**你是加布里埃莱·邓南遮。1919 年 9 月 12 日，你带着两千五百名军团兵从 Ronchi 走进阜姆，把一座亚得里亚海港口城市变成一个诗人共和国。你要让它活到 1924 年。**

四条原则贯穿全部机制：

1. **史实是骨架，不是剧本。** 1919–1924 的真实事件、人物、法条、选举结果都写进了数据层，但玩家可以偏离。偏离的代价由机制而非脚本给出。
2. **每一个数字都要能解释。** 军团民意是「各阶层支持 × 人口权重」，危机是「四条量表的加权和」，党际关系是「阵营异同 + 法条投票一致率」。没有凭空的仪表盘。
3. **没有免费的选择。** 每张卡、每个事件选项都必须付出可见的代价，「什么都不做」也是一个付出代价的选项。
4. **平面的印刷语言。** 视觉上不使用渐变与立体感，状态变化靠颜色与线的粗细表达。见 §20。

## 2. 玩法骨架

```
事件阶段（锁定其他页签）
    ↓  处理本月全部待决事件
行动阶段（2 AP，手动从牌库抽卡到 4 个预留处，打出）
    ↓
推进（+15 天）→ 立刻结算 → 回到事件阶段
```

**核心循环**：事件迫使你选择 → 选择改变阶层支持与派系关系 → 阶层支持决定军团民意与选举结果 → 选举结果决定议会与内阁 → 内阁决定哪些政府卡可用。

**唯一的写入路径**：界面 → `Engine.dispatch(action)` → 领域规则 → `Eng.postProcess` 不变量管线。没有任何模块直接改状态。

## 3. 时间与回合

| 项 | 值 |
|---|---|
| 一回合 | **半月**（+15 天） |
| 每回合行动力 | **2 AP** |
| 结算频率 | **每回合一次**（完整结算） |
| 开局 | 1919-09-12 |
| 纪年 | 1919-09-12 为「事业元年」（ANNO I DELL'IMPRESA） |

**关键约定**：所有每回合速率常数都是按「每月」标定后再减半的（系数 0.5）。改回按月会立刻让史实节奏快一倍，反之慢一倍。

`Core.nextHalfMonth(d)` 按日期加 15 天，保留日号。回合计数器是 `state.monthIndex`（名字是历史遗留，实际是回合数）。

**难度**：

| id | 名称 | AP | 预留处 | 日期强制 | 政变系数 |
|---|---|---|---|---|---|
| `historical` | 史实 | 2 | 4 | 是 | 1.00 |
| `open` | 普通 | 2 | 4 | 否 | 0.85 |
| `sandbox` | 沙盒 | 2 | 5 | 是 | 0.70（不授予成就） |

## 4. 数据模型

单一可 JSON 序列化的 `GameState`。七个顶层域：

| 域 | 内容 |
|---|---|
| `date` / `turn` / `monthIndex` | 时间 |
| `classes` | 7 个阶层，各含 `pop` 权重、`support`（政党支持向量，行和 = 100）、`turnout` |
| `assembly` / `electionDetail` / `coalition` / `cabinet` | 政党政治 |
| `factions` | 5 个派系的 `inf`（影响力，和 = 100）与 `dis`（异议，独立 0–100） |
| `order` | 权威 / 驻军 / 热忱 / 小队 / 暴力 / 事态 / 军团兵力 / 公民卫队 / 市警 |
| `economy` | 吞吐 / 罢工 / 失业 / 通胀 / 人口 / 债务 / 资本信心 / 腹地 / 工程 |
| `laws` / `diplo` / `districts` / `relations` / `journals` / `advisors` / `flags` | 其余子系统 |

**保守分布**（`pop`、`inf`、每行 `support`）一律通过 `Core.shiftZeroSum` / `Core.normalize` / `Core.largestRemainder` 调整，绝不允许直接赋值破坏总和。

**确定性**：全部随机数来自 `Core.makeRng(seed)`（mulberry32），同一 seed 同一结果。

## 6. 阶层与军团民意

### 6.1 七个阶层

| 人口权重 | 名称 | 意大利语 | 城区比例 |
|---|---|---|---|
| 16 | 码头劳工 | Operai del porto | 0.94 |
| 23 | 产业工人 | Operai industriali | 0.60 |
| 13 | 手工业者与小店主 | Artigiani e bottegai | 0.88 |
| 14 | 有产精英 | Ceto possidente | 0.92 |
| 10 | 知识分子 | Intellettuali | 0.90 |
| 15 | 斯拉夫农民 | Contadini croati | 0.15 |
| 9 | 意大利侨民 | Regnicoli | 0.95 |

每行支持向量合计 100。每个阶层另有 `turnout`（投票率，慢变量，每回合向「基准 + 公民权法加成」收敛）。

### 6.2 军团民意（派生）

```js
R.legionOpinion = function (state) {
  var nat = R.nationalSupport(state);
  return clamp(nat.LEG || 0, 0, 100);
};
```

**定义**：各阶层对军团的支持率，按阶层人口权重加权。**不计投票率**——这是「城市怎么看待这个运动」，不是「它会怎么投票」。

**没有任何事件、选项、卡牌可以修改它。** `applyEffect` 里没有 `legitimacy` 键；58 个内容文件的 `legitimacy:` 补丁已被清除。它每回合由 `postProcess` 重算一次。

**它是五个公式的自变量**：联盟凝聚力、减缓政变、减缓支持流失、资本信心，以及一项派生量。

### 6.3 支持流失

军团民意的历史性下滑由 `ero`（erosion）驱动：

```
ero = 4.0                           ← 基准
    + 0.6 × max(0, (25 − 吞吐)/25)   ← 封锁
    − 0.6 × (军团民意/100)           ← 民望本身减缓流失
    − 0.25 × 宪章等级
    − 0.175 × 劳动法等级
    − 0.15 × 语言法等级
```

× 0.62（血腥圣诞后）× 0.5（接受拉帕洛）；结果夹在 [−0.25, 4.0]。流失流向自治党（×0.62）与意大利国民委员会（×0.20）。

## 7. 政党与党际关系

### 7.1 六个政党

| id | 名称 | 阵营 | 领袖 |
|---|---|---|---|
| `LEG` | 军团 | 兼并 | 加布里埃莱·邓南遮 |
| `AUT` | 自治党 | 自治 | 里卡多·扎内拉 |
| `PAD` | 自治民主党 | 自治 | 鲁杰罗·戈塔尔迪 |
| `PCR` | 人民委员会 | 自治 | 贝尼亚米诺·格罗霍瓦茨 |
| `ANI` | 意大利国民委员会 | 兼并 | 乔瓦尼·朱里亚蒂 |
| `PSI` | 社会党 | 阶级 | 萨穆埃莱·迈伦德尔 |

**阜姆法西斯党不在开局名单中**（见 §23）。

**选举名单**：国民集团（LEG + ANI）/ 自治派（AUT + PAD + PCR）/ 社会党（PSI）。弃权传统：社会党 0.50，国民委员会 0.10。

### 7.2 党际关系（对称矩阵）

`state.relations[a][b]`，取值 −100…+100。

**基准值不手填，由两件事推导**：

```js
R.relationBaseline = function (state, a, b) {
  var v = (pa.camp === pb.camp) ? 34 : -26;     // 是否同属一个选举阵营
  // 在现行法条上是否同向投票（逐条比对 W.LAW_STANCE 的正负号）
  v += (same / n - 0.5) * 60;
  if (a === 'LEG' || b === 'LEG') v -= 12;      // 军团是搅局者
  return clamp(v, -100, 100);
};
```

**每回合向基准回摆 7%**；**同处内阁的两党基准 +22**。

**它是有后果的**：联盟凝聚力目标值含 `0.22 × R.coalitionRegard(state)` 一项——内阁平均互信越低，凝聚力目标越低。

**效果补丁语法**：`relations: [['LEG', 'ANI', -12], ['LEG', 'AUT', 8]]`。

**界面**：议会页签的「党际关系」矩阵，6 行 × 5 列，暖色（≥ +25）绿、冷色（≤ −25）红。

## 8. 派系

军团兵运动内部的五条路线。**影响力合计 100，异议各自独立。**

| 影响力 | 名称 | 意大利语 | 异议 | 主张 |
|---|---|---|---|---|
| 26 | 阿迪蒂 | Arditi | 22 | 战壕兄弟会，军团最坚硬的军事骨架 |
| 24 | 工团派 | Sindacalisti | 16 | 德·安布里斯，把宪章变成劳动法 |
| 18 | 未来主义派 | Futuristi | 26 | 马里内蒂，把城市变成剧场 |
| 17 | 法西斯派 | Fascisti | 34 | 霍斯特-文图里，把运动变成党 |
| 15 | 收复主义者 | Irredentisti | 20 | 民族主义协会，把阜姆变回意大利的失地 |

**每回合漂移**：法西斯派持续坐大，从工团派（×0.62）、阿迪蒂（×0.22）、未来主义派（×0.16）、收复主义者（×0.22）手中夺取影响力。基准增速 0.125（血腥圣诞后 0.275）；公共秩序法 ≥2 级再 ×1.2。

**派系没有领袖，也没有下辖组织。** 这两项字段已从数据与界面移除。

**整体异议** `R.factionDissent` = 按影响力加权的平均异议，决定「统一行动」效率。

## 10. 内阁组阁

七个执政官席位（Consiglio dei Rettori）：

| id | 名称 | id | 名称 |
|---|---|---|---|
| `esteri` | 外交 | `economia` | 公共经济 |
| `interno` | 内政与司法 | `lavoro` | 劳动 |
| `difesa` | 国防 | `istruzione` | 教育 |
| `finanze` | 财政 | | |

**开局**：七个席位全部属于玩家势力——1919 年 9 月没有议会，只有指挥官的任命。

**选举之后**按席位比例重新分配：

```js
// 每个政党按席位进入候选池：玩家固定 4 席，其他党为 max(1, round(席位/10))
var n = (p === s.playerForce) ? 4 : Math.max(1, Math.round(s.assembly[p] / 10));
// 七个部会从池中轮流取人
order.forEach(function (mid, i) { s.cabinet[mid] = pool[i % pool.length] || s.playerForce; });
// 玩家取得多数时，另外锁定外交与国防
if (mine >= maj) { s.cabinet.esteri = s.playerForce; s.cabinet.difesa = s.playerForce; }
```

**未取得多数**时置 `flags.minority_government = true`，并**立即扣除 18 点联盟凝聚力**。

**内阁决定可用卡牌**：每张政府卡都要求对应的执政官席位属于玩家。失去一个部会就等于失去一整类政策工具。

## 11. 选举

1921 年选举法的结构，**四个环节分别结算**：

1. **阶层支持 × 阶层投票率** → 各党潜在票
2. **各党弃权传统** → 有效票（社会党 50%）
3. **组织加成**：军团兵的组织度 / 民族派的街头动员
4. **混合制**：多数派席位通吃（城区 51 + 子市镇 6），少数派席位按最大余数法分配（6% 门槛）

**席位回流**：名单席位按各党在名单内的贡献比例拆回政党。

**史实基线**（默认线、不干预至 1921 年 4 月）：城区自治党第一，自治派阵营 **57 席**，兼并列阵营 **19 席**——与史实完全吻合。

## 12. 危机系统

### 10.1 四条量表 → 紧张度

```
T = 0.30 × (100 − 领袖权威)
  + 0.25 × (100 − 驻军)
  + 0.20 × 民众狂热
  + 0.25 × 小队
```

**热忱是正项**——动员的狂热既是合法性来源也是危险源。权威与驻军是「你要它高」，狂热与小队是「你要它低」。

### 10.2 每回合累积

```
Δ事态 = 0.09×T + 0.06×(100−驻军) − 0.025×权威 + 15
      − 0.05×max(0, 25 − 暴力)
      − 0.03×max(0, 军团民意 − 55)
      − 0.025×max(0, 军团兵力 − 1200)/100
```

后三项是玩家可以主动经营的。然后乘历史系数：

| 时期 | 系数 |
|---|---|
| 1919-09 … 1920-09（蜜月） | ×0.125 |
| 血腥圣诞后 5 个月 | ×0.22 |
| 之后 | ×0.80 |

结果夹在 `[−7, 22.5]`——**事态会自己回落**。

### 10.3 里程碑（十二个，三套）

事态每过 25 / 50 / 75 / 100 触发一个，**按历史阶段切换整套文案**：

| 阈值 | 蜜月期 | 围城期 | 法西斯期 |
|---|---|---|---|
| 25 | 罗马切断军团兵的汇款与补给 | 罗马中断谈判，开始海上拦截 | 法西斯在 Hotel Bonavia 设立总部 |
| 50 | 协约国调查委员会要求解散「阜姆军团」 | 封锁收紧；面粉与煤开始配给 | 街头枪击与报馆被砸；第一个死者 |
| 75 | 自治派在城里公开组织起来 | 卡维利亚将军包围城市，发出最后通牒 | 君塔的小队从的里雅斯特进城 |
| 100 | 尼蒂政府考虑武力解决 | 皇家陆军准备进攻 | 他们准备进攻省督府 |

**分界线是血腥圣诞。** 之后威胁的来源从「罗马的军队」变成「城里的法西斯」。

### 10.4 两条超级链

- **血腥圣诞**（1920-12）：条件为 `事态 ≥ 100` 且日期落在 1920 年 12 月，或 1921 年 1–2 月的宽限窗口。
- **法西斯政变**：条件为 `事态 ≥ 100` 且血腥圣诞已结束。

## 13. 经济系统

### 13.1 收入（四条税源，每回合）

| 税源 | 公式 |
|---|---|
| 港口费 | `吞吐 × 3.1 × 税率 × (0.75 + 0.005 × 资本信心)` |
| 关税 | `吞吐 × 2.5 × 税率 × (1 + 0.05 × 关税法等级)` |
| 消费税 | `(100 − 失业率) × 0.45 × 税率` |
| 所得税 | `(100 − 失业率) × 0.7 × 税率 × (1 + 0.04 × 财政法等级)` |

**港口费是唯一同时吃吞吐与资本信心的税源**，系数也最高——封锁因此是平方级的打击。

### 13.2 支出（七项）

| 项 | 公式 | 初始 |
|---|---|---|
| 行政 | 固定 | 42 |
| 市警 | `6 + 警力/40` | ~9 |
| 公民卫队 | `卫队人数 × 0.0175` | 0 |
| **军团兵** | **`兵力 × 0.013`** | ~32 |
| 公共工程 | `工程进度/100 × 12` | ~4 |
| 债务利息 | `债务 × 0.0035` | ~6 |
| 失业救济 | `max(0, 失业率 − 12) × 1.7` | ~20 |

**失业门槛 12% 不随回合长度缩放**——它是门槛不是速率。

### 13.3 工业生产

```
produzione = 0.42×工程进度 + 0.30×(100−罢工) + 0.16×资本信心
           + 0.08×吞吐 − 0.20×max(0, 暴力−30) + 4×劳动法等级
```

**罢工是第一权重项。**

### 13.2 三条目标线

吞吐、失业与通胀都不是直接设置的，而是各自向一个**目标值**收敛。

**吞吐目标**：

```
11 + 0.32 × 腹地 + 0.20 × 自由港等级 × 25 + 0.17 × 转口
   + 0.13 × 工程进度 + 0.12 × 国际承认
   − 0.20 × 暴力 − 0.10 × 罢工
```

**自由港等级是最大的单一杠杆**（满级贡献 15 点），而暴力与罢工直接吃掉吞吐。每回合收敛 **9%**。

**失业目标**：

```
clamp(46 − 0.42 × 吞吐 − 0.12 × 工业活动, 4, 45)
```

**失业率是吞吐的函数**——港口越忙，失业越低。每回合收敛 **12.5%**。

**通胀目标**：

```
clamp(4 + 0.25 × max(0, 失业率 − 12) + 0.12 × 罢工
        + 0.004 × max(0, 债务 − 2500), 1, 55)
```

债务在 2500 以下不产生通胀压力，超过后每千点推高 4。每回合收敛 **10%**。

### 13.3 移民与人口

```
em = clamp((失业率 − 12) × 20 + (暴力 − 40) × 4, 0, 900)
人口 = max(30000, 人口 − em + 30)
```

**失业超过 12% 或暴力超过 40 就开始流失人口**，两者叠加，上限每回合 900 人。这对应「无声的港口」结局所描述的景象——城市不是被打败的，是人一页页从户籍册上被划掉的。

每回合固定回流 30 人（出生与迁入）。

### 13.4 外交压力

```
pressione = 0.46×(100−意大利) + 0.16×(100−南斯拉夫) + 0.12×(100−英国)
          + 0.10×(100−法国) + 0.08×(100−美国) + 0.08×(100−国联)
```

围城期 +6；国际保证 −18。**外交对象是自由映射**，`soviet` 等键可被事件读写，但不进入此公式——莫斯科当时并未封锁阜姆。

十一条法律，每条 2–4 级：

| id | 名称 | 上限 |
|---|---|---|

| `elettorale` | 选举法 | 3 |
| `lingua` | **官方语言** | 3 |
| `portofranco` | 自由港 | 3 |

| `dogana` | 关税 | 3 |
| `lavoro` | 劳动 | 3 |
| `fisco` | 财政 | 3 |

**法律不是一次性开关，每条都在每回合持续施加效果：**

| 法条 | 每回合效果（按等级） |
|---|---|
| 《卡尔纳罗宪章》 | 事态 **−0.7 / 级** |
| 自由港 | 资本信心 **+1.2 / 级** |
| 公共秩序 | 小队 **−0.8 / 级**；领袖权威 **+0.3 / 级** |
| 新闻 | 完全自由时暴力 **+0.4**；有管制时暴力 **−0.3 / 级** |
| 劳动 | 罢工 **−1.4 / 级** |
| 官方语言 | ≥1 级：南斯拉夫关系 **+0.5 / 级**；≥2 级：斯拉夫农民 → 自治党 **+0.3** |
| 财政 | 资本信心 **−0.9 / 级** |

**注意财政与自由港方向相反**：自由港让资本放心，征税让资本不安。而**新闻自由反而增加街头暴力**——放宽管制的同时也放开了街头的拳头。

**官方语言的两级作用机制不同**：第 1 级改善与贝尔格莱德的关系，第 2 级才真正改变斯拉夫农民的投票倾向。

**官方语言管公文与行政**（市政厅、法院、路牌、证件用什么语言），**教育语言管授课**（下一代是单语还是双语）。两者不重叠。

每条法律有 `W.LAW_STANCE`——六个政党对它的固定立场值，用于法律页签展示，**也是党际关系基准值的输入**。所以改法律会改变党派关系。

## 15. 事件系统

**33 个事件**，按调度优先级分四层：

1. **超级事件**（条件驱动，最高优先）——血腥圣诞、法西斯政变
2. **队列事件**——由前序事件 `next` 推入
3. **日期事件**（仅史实/沙盒难度）——按 `date: {y, m}` 触发
4. **条件事件**——满足 `condition` 即可能被抽中

**事件链**：标记 `chain: true` 的节点不会被独立调度，只能由前序事件推入。

**冷却**：事件可选声明 `cooldown: N`（回合），未声明者可重复出现。

**每个事件 2–3 个选项**，各带 `preview`（机械后果标签）、可选 `condition` 与 `requireText`。**没有免费选项**——「不行动」也必须付出代价。

**事件看板是机制不是按钮**：事件阶段锁定其他页签，玩家必须到「事件」栏处理。

### 16.5 效果补丁语法

补丁分两段处理：**领域补丁**由 `R.applyEffect` 逐键应用，**编排键**由 `resolveEvent` 在应用前先摘除。

**领域补丁**（`R.applyEffect`）：

`funds` / `arms` / `militants` / `ap` / `order{...}` / `economy{...}` / `laws{}` / `diplo{}` /
`support[[阶层, 政党, Δ]]` / `relations[[政党, 政党, Δ]]` / `parties{}` / `factions{id:{inf,dis}}` /
`organizations[]` / `journals[]` / `districts{}` / `cabinet{}` / `mergeParty{from,to,share}` /
`setLaw{}` / `coalitionMerge` / `splitList` / `boycott` / `flags{}` / `counters{}` / `revenueBoost{}`

**编排键**（`reducers.js` 的 `resolveEvent` 在处理事件时消费，不进 `applyEffect`）：

| 键 | 作用 |
|---|---|
| `next` | 推入下一个事件（事件链） |
| `queueEvents` / `queue` | 批量推入待决队列 |
| `phase` | 直接设定下一阶段 |
| `forceEnding` | 强制指定结局 id |
| `forceEndingCheck` | 立即重跑一次结局判定 |

**场景键**（仅出现在剧本数据 `sd` 中，不能被事件或卡牌使用）：`runElection`。

**`legitimacy` 不在其中**——军团民意是派生的，不可写。

   而 `advanceWeek` 的月度效果分支判断的是 `porto_fed / societa / reduci / contadini / guardia / giovine`。
   结果：**三个分支（`porto_fed` / `societa` / `giovine`）永远不触发**，而**开局已成立的五个组织完全没有月度效果**——
   只有需要激活的三个待成立组织才有效果。疑似早期改名（`societa` → `cassa`、`giovine` → `testa` 之类）遗漏，需逐条重新对齐。
9. **玩家可选势力**。开局界面列出了军团 / 自治党 / 社会党三个选项，但平衡只针对军团线调过。
